## Formato de entrega: qué dicen las guías

El PDF «Fase 3_ Proyecto Semestral.pdf», página 1, pide primera versión implementada, código frontend, navegación funcional, formularios e interfaces principales, versión responsive y repositorio actualizado. No indica expresamente si se entrega un PDF, un ZIP o solo un enlace.

La guía de Fase 1, página 4, y la guía de Fase 2, página 1, sí indican subir un solo PDF con presentación y entregables y agregar en comentario el enlace al repositorio Git. Esa instrucción aparece en esas fases; no se debe presentar como una exigencia explícita del PDF de Fase 3.

Propuesta de entrega para cubrir ambas posibilidades: repositorio GitHub actualizado con el código y README que explique cómo abrirlo; adjuntar un PDF con presentación, resumen de implementación, capturas de escritorio/móvil, validaciones, pendientes y anexo de IA y autoría; agregar el enlace del repositorio en el comentario. Si la actividad de eCampus tiene instrucciones específicas de Fase 3, esas determinan qué adjuntar. No se puede asegurar que con solo pegar un enlace sea suficiente.

GitHub almacena el código. GitHub Pages es opcional para proporcionar un enlace donde probar la web; no es un requisito explícito de la guía disponible. El repositorio de esta carpeta es local y todavía no se ha publicado en GitHub.

Completar antes de entregar: enlace real del repositorio, aportes individuales y enlace de prompts en el anexo IA y Autoría. No se inventan datos del equipo.
